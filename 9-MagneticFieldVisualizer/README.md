# 🧲 Magnetic Field Visualizer

## 🇬🇧 English

An interactive physics and creative coding project built with **HTML, CSS and JavaScript** using the **HTML5 Canvas API**.

Magnetic Field Visualizer allows you to place charges, generate force fields and explore how particles move through electric, magnetic and gravitational fields.

Watch field lines emerge in real time, move charges around the screen and observe how invisible forces shape the motion of particles.

This project combines science, mathematics and visual art into an interactive simulation.

## 🧠 How It Works

Each charge generates a force field.

The field strength decreases with distance:

```text
Force ∝ 1 / distance²
```

Every point on the screen calculates:

```text
Fx
Fy
```

The resulting vector determines:

- field direction
- particle movement
- field line curvature


Negative charges:


Field lines naturally connect:


## 🧠 Jak to funguje

Každý náboj vytváří silové pole.

Síla pole klesá se vzdáleností:

```text
Síla ∝ 1 / vzdálenost²
```

Pro každý bod se počítají:

```text
Fx
Fy
```

Výsledný vektor určuje:

- směr pole
- pohyb částic
- tvar siločar
