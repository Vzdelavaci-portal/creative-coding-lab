## 🧠 How It Works

Lissajous curves are generated using two sine functions:

```text
x = A · sin(a · t + δ)

y = B · sin(b · t)
```

Where:

- A = horizontal amplitude
- B = vertical amplitude
- a = X frequency
- b = Y frequency
- δ = phase shift
- t = time

The ratio between `a` and `b` determines the final shape.

For example:

```text
1:1 → Circle
2:1 → Figure Eight
3:2 → Complex Loop
5:4 → Orbital Pattern
```

By continuously updating the phase and animation values, the curve appears alive and dynamic.

## 🧠 Jak to funguje

Lissajousovy křivky vznikají pomocí dvou sinusových funkcí:

```text
x = A · sin(a · t + δ)

y = B · sin(b · t)
```

Kde:

- A = amplituda osy X
- B = amplituda osy Y
- a = frekvence X
- b = frekvence Y
- δ = fázový posun
- t = čas

Poměr frekvencí určuje výsledný tvar.

Například:

```text
1:1 → Kruh
2:1 → Osmička
3:2 → Smyčka
5:4 → Orbitální tvar
```

Průběžnou změnou času vzniká animovaný efekt.
