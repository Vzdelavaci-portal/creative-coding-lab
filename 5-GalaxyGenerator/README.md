# 🌌 Galaxy Generator

Generate beautiful spiral galaxies, experiment with different numbers of stars and spiral arms, and explore how mathematical formulas can create stunning space-inspired visualizations.

## 🧠 How It Works

The galaxy is generated using polar coordinates.

Each star is assigned:

- A radius from the center
- An angle
- A spiral arm
- A random offset

The star position is calculated using:

```text
x = cos(angle) × radius
y = sin(angle) × radius
```

A spiral effect is created by increasing the angle based on the distance from the center.

This creates the characteristic shape of a spiral galaxy.

The animation works by continuously updating the angle of every star, producing a smooth rotation effect.

## 🧠 Jak to funguje

Galaxie je generována pomocí polárních souřadnic.

Každá hvězda má:

- vzdálenost od středu
- úhel
- přiřazené rameno
- náhodnou odchylku

Pozice hvězdy je vypočítána:

```text
x = cos(úhel) × poloměr
y = sin(úhel) × poloměr
```

Spirální efekt vzniká postupným natáčením úhlu podle vzdálenosti od středu.

Tím vzniká typický tvar spirální galaxie.

Animace je vytvářena průběžnou změnou úhlu každé hvězdy.
