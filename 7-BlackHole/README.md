# ⚫ Black Hole Sandbox

## 🇬🇧 English

An interactive space simulation built with **HTML, CSS and JavaScript** using the **HTML5 Canvas API**.

Black Hole Sandbox allows you to explore a dynamic universe filled with orbiting particles, gravitational singularities and interactive space phenomena. Create matter bursts, spawn mini black holes, launch scan waves and watch particles bend under the influence of gravity.

Unlike a traditional visualization, this project behaves more like a small physics playground where you can experiment with different scenarios and create your own cosmic simulations.

## 🧠 How It Works

The simulation is based on simplified orbital mechanics.

Each particle contains:

- Position
- Radius
- Orbit angle
- Velocity
- Color
- Opacity

Particles continuously orbit while gradually moving inward.

Position is calculated using polar coordinates:

```text
x = cos(angle) × radius

y = sin(angle) × radius
```

As particles approach the center:

```text
radius ↓
speed ↑
```

which creates the illusion of gravitational attraction.

## 🧠 Jak to funguje

Každá částice má:

- polohu
- vzdálenost od středu
- úhel oběhu
- rychlost
- barvu

Pozice se počítá pomocí polárních souřadnic:

```text
x = cos(úhel) × poloměr

y = sin(úhel) × poloměr
```

Čím blíže je částice ke středu:

```text
poloměr klesá
rychlost roste
```

Tím vzniká efekt gravitačního přitahování.
