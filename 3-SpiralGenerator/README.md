## 🧠 How It Works

The spiral is generated using polar coordinates.

Each point is calculated using:

```text
x = cos(angle) × radius
y = sin(angle) × radius
```

Where:

- Angle increases for every point
- Radius grows gradually from the center
- Rotation is continuously updated

This creates a smooth animated spiral pattern.

The mouse interaction introduces additional wave distortions that modify the radius of each point in real time.

## 🧠 Jak to funguje

Spirála je generována pomocí polárních souřadnic.

Každý bod je vypočítán podle vzorců:

```text
x = cos(úhel) × poloměr
y = sin(úhel) × poloměr
```

Přičemž:

- úhel se postupně zvětšuje
- poloměr roste od středu
- rotace se průběžně aktualizuje

Tím vzniká animovaná spirála.

Pohyb myši navíc ovlivňuje poloměr jednotlivých bodů a vytváří deformace v reálném čase.
