# 🎭 Mandala Painter

## 🇬🇧 English

An interactive mandala drawing application built with **HTML, CSS and JavaScript** using the **HTML5 Canvas API**.

Create beautiful symmetrical mandalas simply by drawing with your mouse or touchscreen. Every stroke is automatically mirrored and rotated around the center, producing stunning geometric artwork in real time.

Whether you're experimenting with creative coding, exploring symmetry, or simply relaxing through digital art, Mandala Painter offers an engaging and visually satisfying experience.

## 🎮 Controls

### Drawing

Hold the left mouse button and move the cursor.

Every stroke is:

- Rotated around the center
- Mirrored automatically
- Repeated according to the selected symmetry level

### Symmetry

Controls how many copies of your stroke are created.

Examples:

```text
4  = Simple symmetry
8  = Classic mandala
12 = Detailed mandala
24 = Complex mandala
32 = Highly intricate mandala
```

### Brush Size

Controls the thickness of the drawing line.

### Glow

Controls the intensity of the neon glow effect.

### Color Picker

Choose any color for your artwork.

### Random Color

Generates a random color from a predefined palette.

### Clear Canvas

Removes the current drawing.

### Save PNG

Exports the mandala as a PNG image.

## 🧠 How It Works

The application uses rotational symmetry.

When the user draws a line:

1. The line is drawn normally.
2. The line is rotated around the center multiple times.
3. A mirrored version is generated.
4. All copies are rendered simultaneously.

This creates a symmetrical mandala pattern.

The rotation angle is calculated as:

```text
360° / symmetry_count
```

For example:

```text
12 symmetry segments

360° / 12 = 30°
```

Each stroke is repeated every 30 degrees around the center.

## 🧠 Jak to funguje

Aplikace využívá rotační symetrii.

Při kreslení:

1. nakreslí se původní tah,
2. tah se několikrát otočí kolem středu,
3. vytvoří se zrcadlená verze,
4. všechny kopie se vykreslí současně.

Výsledkem je symetrický mandalový obrazec.

Úhel otočení se počítá:

```text
360° / počet_symetrií
```

Například:

```text
12 segmentů

360° / 12 = 30°
```

Každý tah se tedy opakuje po 30 stupních.
