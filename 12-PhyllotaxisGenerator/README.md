# 🌻 Phyllotaxis Generator

## 🇬🇧 English

### Overview

**Phyllotaxis Generator** is an interactive generative art application built with **HTML5 Canvas**, inspired by the mathematical patterns found in nature.

Using the famous **Golden Angle (137.5°)** and the Fibonacci sequence, the application creates beautiful arrangements similar to sunflowers, pinecones, succulents and flower petals.

The project combines mathematics, animation and creative coding into a visually engaging experience.

# 🎮 Controls

Changes the number of generated particles.

More points create more detailed patterns.

# 🌻 What is Phyllotaxis?

Phyllotaxis is the arrangement of leaves, seeds or petals around the stem of a plant.

Many plants naturally follow mathematical rules that maximize sunlight exposure and packing efficiency.

Examples include:

- Sunflowers
- Pinecones
- Cacti
- Succulents
- Daisies
- Romanesco broccoli

---

# 📐 Mathematics

Each point is generated using:

```text
r = c × √n

θ = n × Golden Angle
```

Where:

- **r** = radius
- **θ** = angle
- **n** = point index
- **c** = spacing constant

The default angle:

```text
137.507764°
```

is derived from the Golden Ratio.
