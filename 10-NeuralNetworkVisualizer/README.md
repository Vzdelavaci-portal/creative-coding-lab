# 🧠 Neural Network Visualizer

## 🇬🇧 English

An interactive neural network simulation built with **HTML, CSS and JavaScript** using the **HTML5 Canvas API**.

Neural Network Visualizer allows you to generate artificial neural networks, propagate signals, simulate learning and explore how information flows through connected layers.

The project combines data visualization, animation and AI-inspired concepts into an engaging interactive experience.

## 🎮 Controls

### Click Neuron

Click any neuron to inject a signal.

```text
Neuron
↓
Signal
↓
Network Activity
```

Signals propagate through connected layers.

---

### Drag Neurons

Move neurons freely.

Connections update automatically.

---

### Generate

Creates a new network.

Available sizes:

```text
Small
Medium
Deep
```

Each generation creates a different structure.

---

### Pulse

Sends signals through the input layer.

Useful for observing network activity.

---

### Train

Activates learning mode.

During training:

```text
Connections strengthen
Signals increase
Network becomes more active
```

Weights continuously evolve.

---

### Random

Creates:

- random network size
- random speed
- random glow
- random theme

---

### Clear Signals

Removes all active signals.

---

### Save PNG

Exports the current visualization as an image.

---

## 🧠 How It Works

The network consists of:

```text
Input Layer
↓
Hidden Layers
↓
Output Layer
```

Each neuron can connect to neurons in the next layer.

Connections have:

```text
Weight
Activity
Strength
```

Signals travel along these connections.

---

## ⚡ Signal Propagation

When a signal is created:

```text
Neuron A
↓
Connection
↓
Neuron B
```

The target neuron becomes activated.

Activation creates a visual pulse effect.

---

## 🎓 Learning Simulation

Training mode modifies connection weights.

Each connection receives small updates:

```text
Weight += Learning Adjustment
```

As weights increase:

```text
Brighter Connections
More Activity
Stronger Signal Flow
```

This mimics the behavior of artificial neural networks.
