# 🎨 Creative Coding Lab

## 🇬🇧 English

Welcome to **Creative Coding Lab** — a collection of interactive creative coding projects built with **HTML, CSS and JavaScript**.

This repository explores the intersection of:

- Programming
- Mathematics
- Visual design
- Animation
- Interactivity
- Generative art

Each project is designed to be lightweight, educational and accessible directly in the browser.

The goal is to demonstrate how code can be used not only to solve problems but also to create beautiful and interactive visual experiences.

## 🇨🇿 Česky

Vítejte v repozitáři **Creative Coding Lab** — kolekci interaktivních projektů vytvořených pomocí **HTML, CSS a JavaScriptu**.

Tento repozitář propojuje:

- Programování
- Matematiku
- Grafiku
- Animace
- Interaktivitu
- Generativní umění

Každý projekt je navržen tak, aby byl jednoduchý, vzdělávací a spustitelný přímo v prohlížeči.

Cílem je ukázat, že programování neslouží pouze k řešení problémů, ale také k tvorbě zajímavých vizuálních efektů, animací a digitálního umění.
